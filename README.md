# 🧠 IdeaForge AI

## 📌 Project Overview
IdeaForge AI is a web-based platform designed to help users discover and generate innovative project ideas across multiple domains such as AI/ML, Web Development, Cybersecurity, IoT, Blockchain, and FinTech.  

It provides structured problem statements, idea generation, and detailed implementation guidance to help users build real-world projects.

---

## ✨ Features

- 🔍 Explore real-world project ideas  
- 🤖 Generate AI-based ideas instantly  
- 📈 View trending and popular ideas  
- ⭐ Save favorite ideas  
- 📊 Detailed project descriptions with steps  
- 👤 Login & Signup system (Local Storage)  
- 🌙 Dark/Light mode support  
- 🏆 Gamification with points and badges  

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Storage:** LocalStorage   
---

## 🧩 How It Works

1. User logs in or signs up  
2. Explores or searches project ideas  
3. Generates new ideas based on domain and difficulty  
4. Saves favorite ideas  
5. Views detailed implementation steps
